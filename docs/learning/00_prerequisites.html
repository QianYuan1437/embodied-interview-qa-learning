开始刷题前：具身智能最小前置知识

这不是第九卷，而是一张“认知地图”。先把下面 12 个支点搭起来，再进入原题库；遇到陌生名词时回到这里定位它属于感知、决策还是执行。

目标：不追求一次记住公式，只要求能说清“输入是什么、输出是什么、为什么需要它、它把结果交给谁”。

0. 先看全局：机器人是一个闭环系统

起点 P01 · 具身智能到底在解决什么问题？

一句话：让智能体在不确定的物理世界中，持续地“观察 → 估计状态 → 决策 → 执行动作 → 再观察”。

  • 感知把相机、雷达、触觉等原始信号变成物体、深度、位姿等信息。
  • 状态估计把多时刻、多传感器信息融合成“机器人现在在哪里、速度多大、周围是什么”。
  • 规划 / 策略根据目标和当前状态决定下一步做什么。
  • 控制把高层动作变成关节力矩、位置或速度命令，并用反馈修正误差。
  • 数据与工程系统保证时间同步、训练、部署、监控和故障恢复。

记忆钩子：感知回答“看到了什么”，估计回答“我在哪里”，规划回答“准备怎么走”，控制回答“这一毫秒怎么动”。

易错：VLA 通常只替代其中一部分决策链路，并不自动解决传感器同步、状态估计、安全控制和实时通信。

1. 数据如何进入模型：张量、形状与坐标

数学 P02 · 为什么看任何模型前都要先写 tensor shape？

张量就是带多个轴的数字数组。图像常写作 [B,C,H,W]，语言 token 是 [B,T]，机器人轨迹可写作 [B,T,D_a]。其中 B 是批量，T 是时间或序列长度，D_a 是动作维数。

矩阵乘法要求相邻维匹配。Transformer 把输入投影成 Q/K/V，本质上是在最后一个特征维做线性变换；卷积则在空间邻域共享参数。读论文或代码时先在每行旁写 shape，很多“看不懂”会变成普通的维度变换。

记忆钩子：先问“每个轴代表什么”，再问“算法做了什么”。

易错：序列维和特征维经常被不同库交换；语义相同不代表内存布局相同。

机器人学 P03 · 为什么同一个位置要注明坐标系？

向量 [x,y,z] 只有绑定坐标系才有物理意义。同一个杯子在相机系、机器人基座系和世界系中的坐标不同。齐次变换 T_A_B 同时表达旋转和平移，可把 B 系表示的点转换到 A 系。

一条典型链路是：相机检测物体 → 通过相机外参转到基座系 → 逆运动学求关节目标 → 控制器跟踪。只要其中一个变换方向、单位或时间戳错了，模型再准也会抓偏。

记忆钩子：任何位姿旁边都默念三个问题——“相对谁、什么单位、哪个时刻”。

2. 模型为什么能学：函数、损失与梯度

机器学习 P04 · 一次训练 step 到底发生了什么？

模型 f_θ(x) 用参数 θ 把输入变成预测；损失 L(f_θ(x), y) 衡量预测与目标的差；反向传播用链式法则求 ∂L/∂θ；优化器沿降低损失的方向更新参数。

监督学习的标签 y 来自数据。行为克隆中，x 是观测和指令，y 是专家动作；视觉分类中，y 是类别。强化学习没有逐步专家标签，而是靠奖励评价一串动作的长期结果。

记忆钩子：数据定义“学什么”，损失定义“什么算错”，优化器定义“怎么改”。

易错：训练损失下降只说明更贴合训练目标，不等于闭环真机成功率提高；分布偏移、时延和数据泄漏都可能让离线指标失真。

深度学习 P05 · Transformer、CNN 与 MLP 各自在做什么？
  • MLP：对特征做全连接变换，简单但不显式利用空间或序列结构。
  • CNN：用局部感受野和参数共享提取图像特征，天然具有局部归纳偏置。
  • Transformer：用 Attention 让每个 token 按内容聚合其他 token，适合语言、图像 patch 和多模态序列。

VLA 常见链路是：视觉编码器把图像变成视觉 token，语言模型融合视觉与指令，动作头输出离散动作 token、连续动作或动作分布。

记忆钩子：编码器负责“把输入变成可用表示”，动作头负责“把表示变成机器人命令”。

3. 时间如何进入问题：状态、轨迹与 Markov 性

序列 P06 · 单帧、状态与轨迹有什么区别？

观测是传感器当下给出的信号；状态是足以预测未来的系统摘要；轨迹是按时间排列的状态、动作和奖励。相机单帧往往看不出速度或遮挡物，因此机器人常处于部分可观测环境，需要历史窗口、RNN/Transformer memory 或滤波器构造 belief。

Markov 性要求：给定当前状态和动作后，未来与更早历史条件独立。真实机器人通常只拿到不完整、有噪声的观测，所以“状态设计”和“历史长度”是工程问题，不只是公式假设。

易错：把 observation 直接称为 state，可能掩盖速度、接触状态或遮挡信息缺失。

4. 两条学习路线：模仿与强化

IL / RL P07 · 行为克隆和强化学习的根本差别是什么？

行为克隆（BC）把专家的“观测 → 动作”当监督学习，稳定、直接，但部署时一旦走到训练数据没覆盖的状态，错误可能逐步累积。

强化学习（RL）根据奖励学习长期决策，能通过试错超越示范，但样本昂贵、训练不稳、奖励设计困难。机器人项目常用“示范预训练 + 仿真 RL 微调 + 安全约束 / 真机校准”的组合。

记忆钩子：BC 问“专家会怎么做”，RL 问“怎样做长期回报最高”。

下一站：先卷一 §2，再卷二 §1–§4，最后卷三 §1。

RL P08 · MDP、Bellman 方程和策略算法是什么关系？

MDP 定义问题：状态 s、动作 a、转移、奖励和折扣。价值函数 V/Q 评价“从这里开始未来能拿多少回报”。Bellman 方程把长期回报拆成“当前奖励 + 下一状态价值”，从而可以递推学习。

值函数方法学习 Q 后选最大值动作；策略梯度直接调整策略概率；Actor-Critic 同时用 Actor 决策、Critic 评价。PPO、SAC、DQN 都是在这张骨架上处理稳定性、探索或样本效率的不同方案。

记忆钩子：MDP 是题目，Bellman 是递推关系，算法是求解方法。

5. 动作为什么不能直接执行：运动学与控制闭环

控制 P09 · 策略输出、轨迹和电机命令之间隔着什么？

高层策略可能输出末端位姿、关节目标、速度或一段 action chunk。运动学把末端目标转换成关节关系；轨迹生成让目标随时间连续；控制器根据反馈误差生成位置、速度或力矩命令；驱动器最终作用于电机。

控制频率通常高于大模型推理频率，因此系统会用动作分块、插值、低层策略或 MPC/WBC 在两次高层推理间持续闭环。安全层还会检查关节限位、速度、碰撞和急停。

记忆钩子：策略说“去哪”，控制器负责“稳稳地到”。

下一站：卷一 §3；腿足方向再读卷六 §1–§3。

6. 为什么需要状态估计与地图

感知 / 导航 P10 · 检测、定位、建图和规划如何串起来？

检测 / 分割回答“物体或可通行区域在哪里”；深度与点云恢复三维几何；SLAM / VIO 融合跨帧视觉与 IMU，估计自身位姿并维护地图；全局规划在地图上找路线，局部规划结合实时障碍生成短时动作；控制器执行并反馈。

语言导航和 ObjectNav 在这条链路上增加语义目标：VLM/CLIP 等模型帮助识别“要找什么”，但几何可达性、定位漂移和碰撞约束仍需处理。

7. 仿真、世界模型与现实差距

Sim2Real P11 · 仿真器和世界模型是不是一回事？

仿真器由物理引擎和场景规则推进系统，通常由人设计、可直接产生传感器与动力学数据。世界模型从数据学习环境动态，在潜空间预测未来，可用于想象训练或规划。两者都能减少真机试错，但误差来源不同。

Sim2Real 关注训练环境与真机的差异：视觉、动力学、接触、执行器、时延和传感器噪声。域随机化让策略见到多种可能世界；系统辨识让仿真参数更接近真机；教师—学生方法让仿真中的特权信息迁移到只用真实观测的策略。

8. 把算法变成系统：数据、频率与验证

工程 P12 · 一个可落地的具身系统最容易在哪些接口失败？

常见失败点不是单个模型，而是接口：传感器时间戳错位、坐标变换方向错误、训练与部署归一化不一致、动作单位不一致、推理抖动、控制频率断层、日志缺字段、离线评测与真机目标不一致。

排查时按链路固定顺序：输入是否正确 → 预处理是否一致 → 模型输出是否合理 → 后处理 / 坐标 / 单位是否正确 → 控制器是否跟踪 → 环境是否超出数据分布。一次只改一个变量，并保存可复现的日志与视频。

记忆钩子：端到端模型不等于端到端责任；系统每一段都要有可观测指标。
